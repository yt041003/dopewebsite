# Twynzo: 30 / 60 / 90 day growth roadmap

Dates are relative to this release. Priorities respond to evidence, not guaranteed traffic targets.

## First 30 days: establish the baseline

- Follow SEARCH-CONSOLE-PLAYBOOK.md: verify the correct property, confirm the 72-URL sitemap is read, inspect representative pages and selected canonicals.
- Record discovery/indexing states by locale, errors, non-branded impressions, queries and mobile/desktop differences. Investigate meaningful exclusions before adding pages.
- Review the richer 16-type/DOPE pages and two relationship guides for reader usefulness. Keep stable URLs and test the content → quiz → result → guide/another quiz loop.
- Measure lab performance with repeatable conditions and field CWV if available. Check reduced-motion/save-data behavior and touch layouts.
- Define a privacy-respecting analytics plan with the owner before enabling a provider. Current anonymous completion counters do not measure funnel conversion.
- Confirm public operator/contact details and actual retention practices before expanding monetization; do not invent legal or professional claims.

## Days 31–60: improve demonstrated demand

- Review queries every 2–4 weeks, especially relevant positions 8–30 with useful impression volume. Improve intent, examples and titles when evidence warrants.
- Choose at most a few distinct guides from SEO-CONTENT-MAP.md based on observed questions. Deepen existing profiles when a separate article would duplicate them.
- If analytics is approved, establish quiz start/completion, related-test, guide-to-quiz and share-intent baselines using aggregate events only. Compare meaningful sample sizes by locale/device.
- Prototype a compatibility reflection tool using the private model; test whether paired preference prompts help conversation. No predictive percentage, all-pair SEO generation or paid compatibility claim.
- Draft a premium report sample and review usefulness beyond free content. Keep paid content separate and require future server-side entitlement checks; the current coffee link is not a report checkout.

## Days 61–90: small, reversible revenue experiments

- Reassess indexed pages, non-branded clicks, returning use (only if measured) and progression between tests. Report both improvements and uncertainty.
- Consider one real disclosed affiliate resource only if it directly helps a reader. Never fabricate recommendations or endorsements.
- Evaluate ad eligibility and revenue with the owner. Enable at most a secondary article/result placement with fixed dimensions; never inside question navigation. Compare layout stability and quiz completion before expanding.
- Launch a paid report only after real content, pricing, fulfillment, refund/support and verified payment entitlement exist. Do not hide useful free SEO content to manufacture value.
- Publish a pair-specific evergreen page only if distinct demand and substantive original guidance justify it. Tool coverage of 256 inputs is not a reason to index 256 pages.
- Continue the 2–4 week search feedback loop. Scale what serves users; remove or merge low-value overlap rather than targeting page count.
