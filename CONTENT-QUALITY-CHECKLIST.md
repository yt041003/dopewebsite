# Index eligibility and editorial review

Reusable templates do not make content ready to index. Each published page needs a human editorial decision as well as automated checks.

## Hard gates — any failure blocks indexing

- One distinct user question and a useful answer; merge with an existing page when intent substantially overlaps.
- Original body with a concrete situation, meaningful limitation and actionable next step where appropriate. No word-count target or type-code replacement content.
- Complete natural Traditional Chinese and English counterparts before reciprocal alternates.
- Unique, accurate title, H1 and description. Clean self-canonical and real hreflang URLs.
- Server-visible useful content, internal links and relevant quiz CTA on guides/profiles.
- No fabricated credentials, dates, validation, diagnosis, ratings or relationship success scores.
- Relevant links in and out; no orphan route, placeholder offer, broken destination or hidden SEO text.
- Mobile reading and keyboard navigation verified; no blocked quiz, horizontal overflow or intrusive overlays.
- Structured data reflects visible content; robots, sitemap, metadata and 404 checks pass.

## Review record

Record intent, existing-page comparison, examples, editorial reviewer/date when real, bilingual review, technical checks and decision. Internal drafts must stay outside the public registry until ready; use `index:false` only for a deliberately accessible nonindex page. Never link unreleased pair routes. Canonical is not a substitute for keeping private session data private.

## Improvement rubric (0–2 each; not a ranking metric)

Score usefulness, differentiation, clarity, practical examples and next-step relevance. 0 = missing, 1 = partial, 2 = clear and useful. A page with any zero needs revision before publication; a numeric total never overrides the hard gates. Legal/trust and hub pages are judged by their own user purpose rather than article length. Manual review remains required because automated string checks cannot detect filler or unsupported claims.
